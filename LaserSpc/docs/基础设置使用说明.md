# LaserSpc 基础设置使用说明

## 1. 入口

应用启动后，主窗口右上角提供 `基础设置` 按钮。

点击后可配置：

1. 是否优先使用 MySQL 数据源
2. MySQL 主机、端口、数据库名、用户名、密码
3. 默认查询天数

## 2. 配置文件位置

默认情况下，配置会保存到应用程序目录下：

```text
config/laserspc.ini
```

如果当前从构建目录启动：

```text
/root/qt-program/LaserSpc/build/config/laserspc.ini
```

测试或特殊部署场景下，也可以通过环境变量覆盖配置文件路径：

```bash
export LASERSPC_CONFIG_FILE=/custom/path/laserspc.ini
```

## 3. 保存后的生效方式

点击保存后，程序会立即执行以下动作：

1. 持久化配置到 `INI` 文件
2. 根据新的默认查询天数重建筛选栏默认时间范围
3. 重新创建仓储
4. 优先尝试连接新的 MySQL 配置
5. 如果 MySQL 不可用，则自动回退到 Mock 仓储
6. 在状态栏刷新当前数据源状态

## 4. 数据源回退策略

当 `优先使用 MySQL 数据源` 打开时：

1. 连接成功：使用 `MySQL Repository`
2. 连接失败：自动回退 `Mock Repository (MySQL fallback failed)`

当该选项关闭时：

1. 直接使用 `Mock Repository`

## 5. 配置优先级

当前配置优先级如下：

1. 环境变量
2. `config/laserspc.ini`
3. 程序内默认值

其中数据库相关环境变量包括：

```bash
export LASERSPC_USE_MYSQL=1
export LASERSPC_DB_HOST=127.0.0.1
export LASERSPC_DB_PORT=3306
export LASERSPC_DB_NAME=laser_spc
export LASERSPC_DB_USER=laserspc
export LASERSPC_DB_PASSWORD='LaserSpc#2026'
```

## 6. 默认值

当前默认配置：

```text
use_mysql=true
default_query_days=7
host=127.0.0.1
port=3306
database=laser_spc
user=laserspc
```

## 7. 验证建议

保存配置后，可以通过以下方式验证：

```bash
QT_QPA_PLATFORM=offscreen /root/qt-program/LaserSpc/build/LaserSpc
```

若日志输出为：

```text
[LaserSpc] Using data source: MySQL Repository
```

说明当前真实数据库链路已生效。
